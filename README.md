
# Cisco Networking Academy – Networking Labs

A collection of hands-on networking labs developed during Cisco Networking Academy training using **Cisco Packet Tracer**.

The repository covers practical implementation and configuration of network infrastructure, IP addressing, routing, address translation, and network segmentation.

## Technical Coverage

### 1. IP Addressing & Subnetting
- 10-subnet network design and subnetting
- IPv6 addressing and configuration
- Variable Length Subnet Masking (VLSM)
- DHCP-based dynamic IP allocation

### 2. Routing & Network Infrastructure
- Interconnected router configuration
- Frame Relay multipoint topology
- Router-to-router connectivity
- Network segmentation and host allocation

### 3. Network Address Translation
- NAT configuration
- Port Address Translation (PAT)
- Static NAT
- Private-to-public static NAT mapping
